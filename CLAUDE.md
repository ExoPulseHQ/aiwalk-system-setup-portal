# aIwalk System Setup

## Design system

Read `DESIGN.md` before any visual or UI change (anything under `desktop/ui/`: markup, CSS, icons, wording on screen).
It holds the approved look: tokens, type scale, colour roles, icon rules, the ink rendering and what never to do.
Do not deviate from it without the client's approval; when a change needs a new pattern, ask first, then record the decision in its decisions log.
Check the result in the browser preview (`desktop/preview/README.md`), light and dark, at 980x720 and under 700px.
